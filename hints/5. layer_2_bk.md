# layer 2 


##  NOTE!!
- L2 Data is backed-up in two stages:
-- Snapshot (LUKS Partition)
-- Incremental Backups (Using Duplicity to backup modified key files from local to a secure location)
- Each time when a new snapshot is created, latest duplicity backup needs to be sync. with the previous snapshot data.


## Incremental Backup:
- Using the pub. key to encrypt the duplicity data.
- Need to use the pri. key to decrypt the data.
